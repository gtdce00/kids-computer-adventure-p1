ห้องเกมการศึกษา ครูคอม — ชุดเล่นออฟไลน์ (ไม่ต้องติดตั้ง)
==========================================================
1) คลิกขวาที่ไฟล์ zip > Extract All (แตกไฟล์ทั้งหมด) วางโฟลเดอร์ไว้ที่ Documents หรือไดรฟ์ D:
2) ดับเบิลคลิก INSTALL-Desktop-Icon.vbs  จะได้ไอคอน "ห้องเกมการศึกษา ครูคอม" บน Desktop
   (หรือดับเบิลคลิก index.html เพื่อเปิดเล่นได้เลย)

ไฟล์ในโฟลเดอร์
- index.html      = ห้องเกม (หน้ารวมเกมทุกชั้น)
- p1/index.html   = KIDS COMPUTER ADVENTURE ป.1 (เล่นออฟไลน์ได้)
- fonts/          = ฟอนต์ของหน้าห้องเกม
หมายเหตุ: เกมที่ลิงก์ไปเว็บอื่นต้องต่ออินเทอร์เน็ต
ข้อมูลนักเรียนเก็บในเครื่องนี้ ควร "สำหรับครู > ตั้งค่า > สำรองข้อมูล" ทุกสัปดาห์
